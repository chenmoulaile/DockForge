# T-075 证据汇总与诚实边界

## 交付物

| 模块 | 文件 | 作用 |
|---|---|---|
| HTTP 传输 | `src/platform/http_client.{h,cpp}` | WinHTTP 阻塞式 `HttpsGetText`（connect/send/receive 各自 timeout，resolve 固定 5s） |
| 密钥 | `src/core/secrets.{h,cpp}` | `ReadSecrets` 只读 `%APPDATA%\DockForge\secrets.json`（`DOCKFORGE_SECRETS_PATH` 可覆盖），值从不进日志 |
| 天气模型 | `src/dock/weather.{h,cpp}` | 纯函数（UrlEncode/GeocodePath/ForecastPath/WeekdayLabel/ParseGeocode/ParseForecast/KindFromWmo）+ `Host`（单 worker 线程） |
| 悬停弹窗 | `src/dock/weather_popup.{h,cpp}` | GDI 预报弹窗，folder_panel 同族，双缓冲绘制 |
| 渲染 | `src/dock/dock_view.{h,cpp}` | `DrawWeatherGlyph` 七种 Kind + `ComputeWeatherGlyphLayout` + `WeatherTextFor` |
| 配置 | `src/core/config.{h,cpp}` | `WeatherConfig`（默认关闭）+ `SameWeather` + `WeatherRefreshMinutesRange` 5..360 |
| 设置 UI | `src/settings/settings_window.cpp`、`settings_model.{h,cpp}` | Behavior 分节三行（enabled / city / refresh_minutes）+ `City` 字段类型 |
| 集成 | `src/main.cpp` | fixture tile、host 启停、dwell 弹窗、点击刷新、ConfigChanged 重应用、拖拽排除 |

## 诚实边界（未验证项）

1. **amap provider 未实现**：DoD 1 的入口存在（Key 只从 secrets.json 读、只记字节数不记值），
   但 provider=="amap" 时 worker 明确发布 `amap provider not implemented` 失败快照，
   不伪造任何请求。Open-Meteo 无 Key 链路是实际可用路径。
2. **真实网络下未实机截图**：dock 图标 glyph/温度叠加与悬停弹窗的像素级外观未在
   本机 UI 会话内截图验证（运行环境无交互桌面）。绘制路径由 27 个 weather 单测 +
   dock_view 现有渲染契约覆盖，几何由 `ComputeWeatherGlyphLayout` 单元断言。
3. **设置窗口三行控件未实机点击**：与 T-062/T-069 的 Export/Import 按钮同一
   WM_COMMAND → RecordEdit 转发路径；模型层 6 单测覆盖钳制、回显与落盘 round-trip。
4. **IP 定位未使用**：Open-Meteo 无 IP 定位接口，城市由用户手动指定（DoD 2 的兜底路径）；
   amap 的 IP 定位随 provider 一起留待实现。

## 复现命令

```powershell
cmake --build D:\MacDock\build -j 8
& D:\MacDock\build\bin\dockforge_tests.exe                 # 416 cases / 4381 assertions
& D:\MacDock\build\bin\dockforge_tests.exe "[weather]"     # 27 cases / 138 assertions
& D:\MacDock\build\bin\dockforge_tests.exe "[settings]"    # 10 cases / 53 assertions
```

探针钩子：`DOCKFORGE_WEATHER_API_HOST` 覆盖 API 主机；`DOCKFORGE_WEATHER_PREVIEW=0` 关闭悬停弹窗；
`DOCKFORGE_SECRETS_PATH` 指向隔离 secrets.json。
