3. 探针过程中发现并修复的产品缺陷（本次任务外收益）
==========================================================================
设置窗口的所有控件通知自 T-050 起从未到达主窗口：控件 parent 是 STATIC 容器
pane，BUTTON/EDIT/COMBOBOX 的 WM_COMMAND 只发给直接 parent，而系统 STATIC
窗口过程不向上转发。此前 T-050/T-051/T-060/T-061 的探针全部走 RecordEdit 文件
通道，绕过了真实控件通知路径，因此从未暴露。真实用户点击设置控件等于无效。
修复: SettingsWindow::SubclassPane —— pane 子类化转发 WM_COMMAND 给主窗口
（src/settings/settings_window.cpp，SetPropW 保存原过程）。
证据: 探针 run5 修复前 BM_CLICK 后 app 日志无 'opened log folder'；修复后同一
命令日志出现该行且 Explorer 窗口真实打开（probe.txt Part E）。

4. 诚实边界 / 未验证项
==========================================================================
- dump 的符号化调试器加载验证未做：本机无 WinDbg/cdb/lldb。dump 被工具识别为
  合法 Mini DuMP（13 streams）+ 源码用标准 API + spike 同参数集成功，但
  "能在调试器里打开看到调用栈" 这一步未实测。
- MiniDumpWriteDump 无超时参数：2 秒预算靠 MiniDumpNormal + 实测背书
  （spike 62ms / 探针 150/171/120/109ms），不是可强制的看门狗。若未来实测
  超预算需评估看门狗线程方案（spikes/t062_dump/findings.md 已记录）。
- 真实 10MB / 14 天路径未等真实时间与容量：通过 env 覆盖（20000B / 1 天 /
  默认 14 天窗口）实测同一代码分支；产品默认值常量在 log_rotation.h 与
  Logger::Init 直接可读，无独立分支。
- C-07 契约原文"保留 7 天"与 T-062 DoD"保留 14 天"冲突：按 DoD 执行并在
  CONTRACTS.md C-07 追加演进注记（保留 14 天 + 10MB 上限，T-062 起）。
- 探针 Part D 会让真实 app 崩溃一次（0xC0000005），崩溃转储与 taskbar-crash.txt
  标记写入本机真实 %LOCALAPPDATA%（T-061 探针既有行为，无隔离通道可写）。
- SetUnhandledExceptionFilter 覆盖不了 abort()/CRT terminate（T-061 已声明，
  DoD 只要求未处理异常路径）。

5. 会话内迭代记录（探针自身缺陷，产品代码最终零未诊断问题）
==========================================================================
- run1: E1 设置窗口未找到 —— PowerShell 5.1 把 P/Invoke string 参数 $null 编组
  为 ""（非 NULL）：FindWindowW(cls,"") 只匹配空标题窗口；FindWindowExW(..,$null,..)
  直接 ERROR_INVALID_NAME(123)。改 [NullString]::Value。
- run3/run4: 扫描不到按钮且 sweep 类名全部单字符（cls=D/cls=S）——
  W6.GetClassNameW 缺 CharSet.Unicode，ANSI 编组进 W 函数（T-061 同款陷阱）。
- run6: pane 子类化修复第一次编译失败（static 成员访问 hwnd_），探针跑了旧
  二进制 —— 门禁 build 输出里有 error 行，本轮起每次先确认 build 干净。
- run7: BM_CLICK 生效但 Explorer 标题精确匹配失败 —— 实测标题为
  "logs-e - 文件资源管理器"（含本地化后缀），改 CONTAINS 匹配。
- 截图两次抓到浏览器 —— SetForegroundWindow 从后台被拒（项目已知 gotcha），
  改 PrintWindow(PW_RENDERFULLCONTENT)，与遮挡无关。
