# 对标矩阵 · MyDockFinder 1.18 功能对齐审计（T-200）

- 审计日期：2026-10-25
- 审计基准：MyDockFinder 1.18 正式版用户可感知功能集（官方 README、Steam 商店功能列表、更新日志；不逆向其代码）
- 状态定义：**已对齐**（有实现且有实测证据）/ **部分对齐**（有实现但有已知差距）/ **缺失**（未实现，已排任务）/ **明确不做**（附理由）

| Steam 生态三件套（Workshop/云/成就） | ADR-0017：开源分发走 GitHub |
| WinRing0 温度驱动 | Windows Security 已标记漏洞；用 WMI 或降级 |

## 结论

- **已对齐 18 项 / 部分对齐 3 项 / 缺失 27 项 / 明确不做 5 项 / BLOCKED 2 项**（按上表逐行计数）。
- 缺失项绝大多数已被既有队列（M4/M5/P1.5/P2）覆盖；P4 新增的净增量是 T-201..T-208（最小化动画、蒙版、隐藏模式、窗口避让、滚轮中键、监控增强、日历、3D 沉浸）。
- 审计同时抓到并修复了一个 P0 缺陷（图标上下颠倒，见 1.5）——用户实测发现，本轮会话闭环。
- 执行顺序不变：P1（T-050 起）→ P1.5 → P2 → P3 → P4 修复任务（T-201 起）→ T-212 终审。
